How it works

One sentence to Claude. Six passes on the timeline.

Open the folder in Claude Code and say what you want, like “Edit raw/my-clip.mp4 into a 30-second Instagram reel with captions.” The hub skill picks the right editor and runs these passes in order.

00:00

Speech becomes text

Transcribed on your machine with whisper.cpp. Free, private, word-timed.

00:10

Dead air and retakes go

Pauses, stutters and false starts are cut between phrases, never inside one.

00:20

Every point gets a visual

Zooms, cards, lower thirds and UI B-roll built in HyperFrames and GSAP.

00:30

Captions that read

Word-timed, in your brand's look, and never over the mouth.

00:40

Every frame is checked

Preflight, validators and a contact sheet before anything is called done.

00:50

You rate, it learns

Yes, Maybe or No on each option. Your taste is saved per brand.

Install

Two ways in. Both free.

The whole workspace

Skills, style library, local transcription and the renderer. Best for editing real footage.

git clone https://github.com/F0rger123/claude-video-editing-god-mode.git
cd claude-video-editing-god-mode
npm install
npm run setup   # checks Node 22+, FFmpeg, Chrome, renderer
npm run demo    # renders a starter video, no footage needed

Then open the folder in Claude Code and say Edit raw/my-clip.mp4 into a 30-second reel with captions.

Node.js 22+FFmpegChromeClaude Code or Codex

Just the skills

Add them to Claude Code as a plugin, in any project.

/plugin marketplace add F0rger123/claude-video-editing-god-mode

Paid services (ElevenLabs, OpenAI and others) are optional. Add your own key to .env only if you want them.

Free and local first

Transcription, cutting and rendering run on your computer.

No music unless asked

Sound follows what's on screen. Your own sound folder comes first.

Your footage stays yours

Raw clips, transcripts and renders never go into the repo.

Checked before handover

Nothing is called done until the render has been watched.
